# 🛍️ E-Commerce Sales Analysis Using SQL

## 📊 Project Overview
This project focuses on analyzing e-commerce sales data using **SQL** to uncover key insights about sales performance, customer behavior, and product trends.

## 🧠 Objectives
- Identify top-performing products and regions  
- Calculate revenue, profit, and order volume trends  
- Find patterns in customer purchases  
- Optimize decision-making using data-driven insights  

## 🧰 Tools Used
- MySQL Workbench  
- SQL (Joins, Aggregations, Subqueries, CTEs)

## 📈 Key Insights
- Found top 5 products contributing to over 60% of total revenue  
- Identified high-performing regions by monthly sales growth  
- Derived insights that could help marketing and inventory strategies
